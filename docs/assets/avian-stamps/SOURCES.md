# Avian Atlas stamp embed

The CSS and JavaScript in this directory mirror the production stamp runtime
from the AvianVisitors repository. The illustration files are lossless WebP
derivatives of the matching bundled AvianVisitors PNGs, sized for this article.
The paper, concrete, grain, and sparrow reference textures are lossless WebP
derivatives of their documented AvianVisitors sources.

The bird-name comparison uses the same Caveat font and OFL license shipped in
`avian/frontend/fonts/` by AvianVisitors. The caption side reproduces the
original under-bird renderer from commit `017739f2`; the contour side uses the
current production DOM and American Crow baseline captured at the article's
fixed example dimensions. Neither label is redrawn for the documentation.

Font authorship and licenses are recorded in `fonts/stamp/SOURCES.md` and
`fonts/stamp/OFL-1.1.txt`. Texture provenance is recorded in
`assets/stamp/SOURCES.md`.
